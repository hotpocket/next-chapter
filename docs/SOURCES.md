# Sources & provenance

Every narrated claim in the trilogy traces to a pinned source. Chapter text
was researched from these trees; audio was generated by the vendored
repo-story pipeline (Chatterbox TTS, owner's voice, owner's GPU — see
ADR 0003: generation is offline; this site only plays).

## Book 1 — landry-ui

- Source: [hotpocket/landry-ui](https://github.com/hotpocket/landry-ui)
  at commit `67ffdec` (also the player this site runs — see
  [PROVENANCE.md](PROVENANCE.md)).
- Researched from a full-history clone (64+ commits); dates and commit
  hashes quoted in narration are from that log.

## Book 2 — repo-story

- Source: the vendored tree at [`repo-story/`](../repo-story/) in this
  repository — a scrubbed commit-replay of the private original. Each
  replayed commit carries a `Replayed-From: repo-story@<sha>` trailer with
  its original author date (23 replayed + native commits; see the README
  banner there for exclusions and redaction conventions).
- The book narrates the replayed history; `[bracketed]` tokens in that tree
  are redactions, and the narration inherits their boundaries.

## Book 3 — next-chapter

- Source: this repository, **narrated through commit `8295cae`**
  (ADR 0009: the closing book cannot contain its own generation — it was
  generated last and trails HEAD by construction). Everything after that
  commit — including the assembly of this site — is outside the book's
  narrated range.
- The checkable record the book defers to: [`vault/decisions/`](../vault/decisions/)
  (ADRs + index), `vault/sessions/` (recaps + verbatim prompt exports),
  `llm-docs/` (plan, wargames, vets).

## Pipeline

- Generation: `repo-story/` (SKILL.md phases + build scripts), run via the
  in-repo run folders (gitignored). Summary tracks are Phase 5c artifacts —
  condensed by the same pipeline, ~12–18% of each chapter.
- Site assembly: [`scripts/build-trilogy-site`](../scripts/build-trilogy-site)
  from [`scripts/trilogy.json`](../scripts/trilogy.json).

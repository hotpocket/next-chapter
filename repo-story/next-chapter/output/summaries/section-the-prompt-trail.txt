This part of the repo is the prompt trail: the machinery that publishes not just the code but the prompts that made it. Its core is a bash script named export-prompts. It finds the newest Claude Code transcript for the repository, keeps only the human's user messages, and drops assistant replies, tool results, system notifications, and skill-expansion blocks. Each surviving prompt is redacted inline, with the value replaced but the line preserved: emails, credentials, private keys, token-shaped strings, and home paths each become a marker. It writes one numbered file of verbatim prompts per session, tagged and linked to that session's recap, then runs the leak-scanner gitleaks over what it wrote.

A companion test script, test-export-prompts.sh, asserts those rules against a fixture: tool results never become prompts, home paths collapse to a tilde. A plausibility rule, earned after task-notification blocks once inflated the counts, says an implausibly low count means the transcript format drifted, so stop and investigate. The README's Sessions and prompts table links every recap to its export. A gate named check-session-wrapup re-derives those counts from the exports themselves, so the table, the curated index, and the glossary cannot drift apart. And config-history.md is the reviewer's decoder ring, defining every slash command the prompts invoke. Wrapping it all is public-repo hygiene: a scan-before-commit across credentials, identity, and machine internals, plus a private token-map scan for identifiers regex cannot see, added after quoted agent output leaked past gitleaks. A July twentieth request to publish the prompts drove every piece.

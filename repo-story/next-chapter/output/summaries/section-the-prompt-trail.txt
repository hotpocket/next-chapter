This part of the repo is the prompt trail: the machinery that publishes not just the code but the prompts that made it. Its core is a bash script named export-prompts. It finds the newest Claude Code transcript for the repository, keeps only the human's user messages, and drops assistant replies, tool results, system notifications, and skill-expansion blocks. Each surviving prompt is redacted inline, with the value replaced but the line preserved: emails, credentials, private keys, token-shaped strings, and home paths each become a marker. It writes one numbered file of verbatim prompts per session, tagged and linked to that session's recap, then runs the leak-scanner gitleaks over what it wrote.

A companion test script, test-export-prompts.sh, asserts thirteen checks against a fixture, including that tool results never become prompts and that home paths are redacted. A plausibility rule, earned after task-notification blocks once inflated the counts, says an implausibly low count means the transcript format drifted, so stop and investigate. The README's Sessions and prompts table links every recap to its export, one hundred ten prompts across four sessions, and config-history.md serves as the reviewer's decoder ring with a glossary rule for slash commands. Wrapping it all is public-repo hygiene: a scan-before-commit across credentials, identity, and machine internals, plus a private token-map scan for identifiers regex cannot see, added after quoted agent output leaked past gitleaks. A July twentieth request to publish the prompts drove every piece.

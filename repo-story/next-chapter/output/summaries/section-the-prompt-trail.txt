This part of the repo is the prompt trail: the machinery that publishes not just the code but the prompts that made it. Its core is a bash script named export-prompts. It finds the newest Claude Code transcript for the repository, keeps only what the human typed, and drops assistant replies, tool results, system notifications, skill-expansion blocks, and any record the harness flagged isMeta — the marker that catches injected skill bodies the older prefix filter missed. Each surviving prompt is redacted inline, the value replaced but the line preserved: emails, credentials, private keys, token-shaped strings, and home paths each become a marker. It writes one numbered file of verbatim prompts per session, linked to that session's recap, then runs the leak scanner gitleaks over what it wrote. A companion test script, test-export-prompts.sh, asserts those rules against a fixture transcript. A plausibility rule, earned after task-notification blocks once inflated the counts, says an implausibly low count means transcript drift, so stop and investigate. A gate named check-session-wrapup re-derives every published count from the export files themselves and fails when the Session Log, the README's table and totals, prompt-history.md, the curated index, or config-history.md's command glossary disagrees. Wrapping it all is public-repo hygiene: a scan before every commit across credentials, identity, and machine internals, plus a private token-map scan for identifiers regex cannot see, added after quoted agent output leaked past gitleaks. A July twentieth request to publish the prompts drove every piece.

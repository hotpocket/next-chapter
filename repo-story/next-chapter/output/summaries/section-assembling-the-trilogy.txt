This chapter is the assembly: how three separate pipeline runs become the single published site the player loads. The registry, scripts slash trilogy dot json, is the plan in data form — a title, a favicon, and three books, each naming a slug, a manifest, a transcripts file, and a description, all pointing into gitignored run folders. The assembler, scripts slash build dash trilogy dash site, reads that registry and, per book, converts the manifest by reusing one shared function imported from the pipeline's own code rather than reimplementing it. It copies audio with a size-compare skip and stale-file pruning, prefixes filenames with each book's slug, merges all transcripts into one file, and cache-busts that file with the first eight characters of its content hash. It generates index dot html with the books inlined.

Its sharpest rule is provenance: it pins an exact commit for the player only when the player directory is a real checkout of the external landry-ui project, because pinning any enclosing repo's HEAD would be, in the code's words, provenance theater. That fix is frozen as a negative assertion in the fourteen-check test file, which exists because a prompt held the agent to test-first discipline. The vendored generator brought the pipeline in as scrubbed, replayed history. Nothing here deploys — the owner pushes, a hook enforces it — the same public-by-default stance the prompts get next.

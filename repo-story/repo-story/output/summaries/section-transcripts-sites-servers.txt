This part of the artifact turns generated audio into a playable, publishable site. build_transcripts.py produces the read-along: it re-runs the same chunking the audio used, walks the chunk WAV files for their durations, and writes transcripts.json with chapter-relative timestamps, plus a separate summary_chunks timeline for each chapter's short version. build_site.py assembles the standalone site: it copies per-chapter audio, versions everything by an eight-character content hash for durable cache-busting, prunes stale audio, carries an optional feedback-url flag, and links a favicon. luinst fetches the player from landry-ui, a separate component repository, over HTTPS by default, into a gitignored player directory. build_book.sh is the one-command builder: a folder of chapter text in, a standalone site out, with transcripts inlined so no server is needed. Two small servers, serve.py and serve_chunks.py, provide range-capable local preview and a live network playlist of raw chunks. Publishing has one target: the parent next-chapter repository's GitHub Pages folder. No cloud hosting, no deploy scripts; the owner pushes.

Prompts drove the sharp edges. The July twenty-first sessions fixed the summary time display, corrected the favicon in two steps, insisted on a no-server local build, and retargeted publishing away from cloud hosting, all verbatim in the record.

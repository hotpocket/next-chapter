Chapter three is about taking a book offline and installing the player as an app. One honesty note governs it: everything here was built in an early-April twenty twenty-six burst, before this project exported its prompts, so no verbatim prompt survives — every attribution is a paraphrase of the commit trail and a detailed session note dated the third of April.

Four features. First, the per-book download button, downloadForOffline: one press caches every chapter, guarded by a screen wake lock and a refresh-confirmation prompt, counting "chapter i of total" as it goes, storing both the full and summary tracks, with each chapter kept as its own cache entry keyed by absolute URL, so adding chapters never invalidates saved ones. Second, the service worker, sw.js, which keeps two named caches — audiobook-shell for the app, served network-first, and audiobook-audio for chapters, served cache-first — split deliberately so a code update never wipes downloaded audio. Third, offline seeking: a serveRange helper slices a cached whole file into byte-range partial responses using Blob dot slice rather than arrayBuffer, which the note calls the difference between twenty-second and instant seeks; a companion lesson is that cache keys must be absolute URLs. The chapter also carries two dead ends preserved in the note — an abandoned background-fetch API and tablet out-of-memory crashes — plus a legacy-cache eviction that recalls a bad chapter. Fourth, the manifest that installs the player as a standalone app with its own icons.

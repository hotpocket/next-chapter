# repo-story — Ubiquitous Language

- **Unit** — one independently explorable project within a target repo. A single-project repo is one unit; a monorepo of skills/plugins is many.
- **Dossier** — the feature-inventory record for one unit (Phase 2). Preserves exact commands, paths, defaults; never summarizes.
- **Chapter (feature cluster)** — a group of features a reviewer tours together: orientation, core workflow, or supporting features (Phase 3).
- **Provenance** — the prompts behind a feature, labeled verbatim (prompt export), paraphrase (recap/commit), or inference (Phase 4).
- **Beats** — the per-chapter notes written by the planner: feature order, must-hit details, prompt citations with labels, one-clause transitions (Phase 5a). The handoff artifact from planning to narration.
- **Section** — the finished spoken-prose walkthrough for one chapter (Phase 5b).
- **Planning phases** — work done in the main session (Fable): survey, inventory, beats, chapter ordering.
- **Execution phases** — work done by named agents (Opus): exploration, research, section writing.

# repo-story — Ubiquitous Language

- **Unit** — one independently explorable project within a target repo. A single-project repo is one unit; a monorepo of skills/plugins is many.
- **Dossier** — the detailed exploration record for one unit (Phase 2). Preserves exact quotes, numbers, paths; never summarizes.
- **Theme** — a cross-unit idea worth a chapter: a project-independent principle plus its specific implementations (Phase 3).
- **Beats** — the per-theme arc notes written by the planner: narrative arc, must-hit facts, transitions in/out (Phase 5a). The handoff artifact from planning to narration.
- **Section** — the finished spoken-prose narrative for one theme (Phase 5b). One section becomes one chapter.
- **Planning phases** — work done in the main session (Fable): survey, synthesis, beats, chapter ordering.
- **Execution phases** — work done by named agents (Opus): exploration, research, section writing.
- **Lens** — the interpretive angle of the documentary. Emerges from the material; never requested from the user up front.
